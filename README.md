## Currently building

**A Multimodal Cognitive-State-Aware AI Tutor Agent for Personalized Learning** — my final-year project.
A web tutor that reads webcam cues (gaze, blinks, yawns, head pose) and learning behaviour to detect whether a student is focused, distracted, tired or overloaded — then adapts its teaching in real time through an LLM agent, with student profiles and an explainability dashboard.

`React` · `FastAPI` · `MediaPipe` · `LangGraph` · `Whisper` · `Chroma` · `XGBoost`
